# Русификатор Barony

Переведён доступный для локализации текст игры, включая книги и все DLC. Достижения работают.

[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3673951398) · [Поддержать проект на Boosty](https://boosty.to/xlebka)

## Установка

### Через Steam Workshop

1. Подпишитесь на [мод](https://steamcommunity.com/sharedfiles/filedetails/?id=3673951398) и дождитесь загрузки.
2. Запустите игру, выберите **PLAY MODDED GAME** и включите русификатор.

### Вручную из GitHub

1. Скачайте репозиторий: **Code → Download ZIP**.
2. Распакуйте файлы в папку `Barony/mods/BaronyRu`. Папки `books`, `fonts`, `lang` и остальные файлы мода должны лежать прямо внутри `BaronyRu`.
3. Запустите игру, выберите **PLAY MODDED GAME** и включите русификатор.

Бета-ветка и изменение файлов игры не требуются. Если ранее включали «Только чтение» для `Barony/books/compiled_books.json`, снимите эту галочку. Удалять или заменять этот файл не нужно.

Нашли ошибку, обрезанный текст или вылет? Опишите проблему в комментариях [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3673951398) или создайте [issue](https://github.com/Xlebka3003/BaronyRu/issues).
